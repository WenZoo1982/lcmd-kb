## 用途

查看当前目录或指定目录中的内容。

## 基本语法

```bash
ls [选项] [路径]
```

## 常用参数

| 想要做什么 | 命令 | 说明 |
|---|---|---|
| 查看当前目录 | `ls` | 简要列出内容 |
| 查看详细信息 | `ls -l` | 显示权限、大小和时间等信息 |
| 显示隐藏文件 | `ls -a` | 同时显示以点开头的项目 |
| 以易读单位显示大小 | `ls -lh` | 文件大小使用 KB、MB 等单位 |

## 常用示例

```bash
ls -lah ~/Downloads
```

以详细格式显示下载目录中的所有项目，包括隐藏文件。

## 必要注意事项

不同 Unix-like 系统可能使用不同实现；本知识库 Linux 内容以常见 GNU 工具行为为基准。
