## 用途

管理 Debian 系发行版软件包。适用于 Debian、Ubuntu 和 Linux Mint。

## 基本语法

`sudo apt 子命令 [软件包...]`

## 常用参数

- update：刷新索引
- upgrade：升级
- install：安装
- remove：卸载
- search：搜索

## 常用示例

```bash
sudo apt install curl
```

## 扩展参数

更多用法请执行 `man apt` 或 `apt --help`（命令支持时）查看。
