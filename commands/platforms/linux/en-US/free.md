## Purpose

Display memory usage. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`free [选项]`

## Common options

- -h：易读单位
- -m：以 MiB 显示
- -s：定期刷新

## Examples

```bash
free -h
```

## More options

See `man free` or `free --help` (if supported) for additional options.
