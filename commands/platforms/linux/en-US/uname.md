## Purpose

Display system information. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`uname [选项]`

## Common options

- -a：显示全部信息
- -r：内核版本
- -m：硬件架构

## Examples

```bash
uname -a
```

## More options

See `man uname` or `uname --help` (if supported) for additional options.
