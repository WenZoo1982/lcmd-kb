## Purpose

Display or set the system date and time. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`date [选项] [+格式]`

## Common options

- -u：使用 UTC
- +%F：日期
- +%T：时间

## Examples

```bash
date '+%F %T'
```

## More options

See `man date` or `date --help` (if supported) for additional options.
