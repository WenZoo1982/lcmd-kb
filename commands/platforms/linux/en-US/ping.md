## Purpose

Test network reachability. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`ping [选项] 目标`

## Common options

- -c：发送次数
- -i：发送间隔
- -W：等待超时

## Examples

```bash
ping -c 4 1.1.1.1
```

## More options

See `man ping` or `ping --help` (if supported) for additional options.
