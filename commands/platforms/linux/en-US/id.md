## Purpose

Display user and group IDs. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`id [选项] [用户]`

## Common options

- -u：用户 ID
- -g：主组 ID
- -G：全部组 ID
- -n：显示名称

## Examples

```bash
id -un
```

## More options

See `man id` or `id --help` (if supported) for additional options.
