## Purpose

Create empty files or update timestamps. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`touch [选项] 文件...`

## Common options

- -a：只更新访问时间
- -m：只更新时间
- -c：不创建文件

## Examples

```bash
touch notes.txt
```

## More options

See `man touch` or `touch --help` (if supported) for additional options.
