## Purpose

Print the current working directory. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`pwd [选项]`

## Common options

- -L：逻辑路径
- -P：物理路径

## Examples

```bash
pwd
```

## More options

See `man pwd` or `pwd --help` (if supported) for additional options.
