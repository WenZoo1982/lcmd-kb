## Purpose

Create directories. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`mkdir [选项] 目录...`

## Common options

- -p：递归创建父目录
- -m：设置权限

## Examples

```bash
mkdir -p ~/projects/demo
```

## More options

See `man mkdir` or `mkdir --help` (if supported) for additional options.
