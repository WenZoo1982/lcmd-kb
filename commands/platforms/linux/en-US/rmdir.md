## Purpose

Remove empty directories. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`rmdir [选项] 目录...`

## Common options

- -p：同时删除空的父目录

## Examples

```bash
rmdir -p old/empty
```

## More options

See `man rmdir` or `rmdir --help` (if supported) for additional options.
