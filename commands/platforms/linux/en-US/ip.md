## Purpose

Show or manage network interfaces and routes. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`ip [选项] 对象 命令`

## Common options

- addr：地址
- link：链路
- route：路由

## Examples

```bash
ip -br addr
```

## More options

See `man ip` or `ip --help` (if supported) for additional options.
