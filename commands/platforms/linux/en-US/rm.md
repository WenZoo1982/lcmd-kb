## Purpose

Remove files or directories. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`rm [选项] 文件...`

## Common options

- -r：递归删除目录
- -f：强制删除
- -i：逐项询问

## Examples

```bash
rm -i draft.txt
```

## More options

See `man rm` or `rm --help` (if supported) for additional options.
