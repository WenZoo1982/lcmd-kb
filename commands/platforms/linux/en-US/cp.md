## Purpose

Copy files and directories. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`cp [选项] 源 目标`

## Common options

- -r：递归复制目录
- -i：覆盖前询问
- -a：尽量保留属性

## Examples

```bash
cp -r project/ backup/
```

## More options

See `man cp` or `cp --help` (if supported) for additional options.
