## Purpose

Display manual pages. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`man [选项] 页面`

## Common options

- -k：按关键词搜索手册
- -f：查询简短说明
- q：退出

## Examples

```bash
man -k network
```

## More options

See `man man` or `man --help` (if supported) for additional options.
