## Purpose

Compress or decompress files with gzip. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`gzip [选项] 文件...`

## Common options

- -d：解压
- -k：保留原文件
- -1 到 -9：调整压缩速度与比例

## Examples

```bash
gzip -k report.log
```

## More options

See `man gzip` or `gzip --help` (if supported) for additional options.
