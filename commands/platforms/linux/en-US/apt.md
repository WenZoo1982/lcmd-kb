## Purpose

Manage Debian-family packages. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`sudo apt 子命令 [软件包...]`

## Common options

- update：刷新索引
- upgrade：升级
- install：安装
- remove：卸载
- search：搜索

## Examples

```bash
sudo apt install curl
```

## More options

See `man apt` or `apt --help` (if supported) for additional options.
