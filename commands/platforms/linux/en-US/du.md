## Purpose

Estimate file and directory space usage. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`du [选项] [路径...]`

## Common options

- -h：易读单位
- -s：仅显示总计
- -d：限制目录深度

## Examples

```bash
du -sh ~/Downloads
```

## More options

See `man du` or `du --help` (if supported) for additional options.
