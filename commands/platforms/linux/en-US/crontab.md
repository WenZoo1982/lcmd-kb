## Purpose

Manage per-user cron schedules. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`crontab [选项]`

## Common options

- -e：编辑
- -l：列出
- -r：删除当前用户任务

## Examples

```bash
crontab -l
```

## More options

See `man crontab` or `crontab --help` (if supported) for additional options.
