## Purpose

Display a line of text. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`echo [选项] [字符串...]`

## Common options

- -n：不输出末尾换行
- -e：解释反斜杠转义（依实现而异）

## Examples

```bash
echo 'Hello Linux'
```

## More options

See `man echo` or `echo --help` (if supported) for additional options.
