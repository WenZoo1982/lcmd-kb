## Purpose

Display the end of a file. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`tail [选项] [文件...]`

## Common options

- -n：指定行数
- -f：持续跟踪新增内容

## Examples

```bash
tail -f /var/log/syslog
```

## More options

See `man tail` or `tail --help` (if supported) for additional options.
