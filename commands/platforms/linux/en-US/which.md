## Purpose

Locate an executable in PATH. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`which [选项] 命令...`

## Common options

- -a：显示 PATH 中所有匹配项

## Examples

```bash
which -a python3
```

## More options

See `man which` or `which --help` (if supported) for additional options.
