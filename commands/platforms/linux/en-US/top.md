## Purpose

Display live process and resource usage. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`top [选项]`

## Common options

- -u：只显示指定用户进程
- 按 q 退出，按 P 按 CPU 排序

## Examples

```bash
top -u $USER
```

## More options

See `man top` or `top --help` (if supported) for additional options.
