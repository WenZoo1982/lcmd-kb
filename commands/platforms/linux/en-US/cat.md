## Purpose

Display or combine file contents. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`cat [选项] [文件...]`

## Common options

- -n：显示行号
- -b：仅为非空行编号
- -A：显示不可见字符

## Examples

```bash
cat -n config.txt
```

## More options

See `man cat` or `cat --help` (if supported) for additional options.
