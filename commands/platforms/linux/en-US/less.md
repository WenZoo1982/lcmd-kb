## Purpose

View text files page by page. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`less [选项] 文件`

## Common options

- /关键词：向后搜索
- ?关键词：向前搜索
- q：退出

## Examples

```bash
less /var/log/syslog
```

## More options

See `man less` or `less --help` (if supported) for additional options.
