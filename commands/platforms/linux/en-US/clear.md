## Purpose

Clear the terminal screen. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`clear [选项]`

## Common options

- -x：不清除滚动缓冲区（终端支持时）

## Examples

```bash
clear
```

## More options

See `man clear` or `clear --help` (if supported) for additional options.
