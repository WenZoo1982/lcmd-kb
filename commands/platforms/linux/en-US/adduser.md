## Purpose

Add users or groups on Debian systems. Available on Debian, Ubuntu, and Linux Mint.

## Syntax

`sudo adduser [选项] 用户`

## Common options

- --disabled-password：不设置密码
- --gecos：设置用户说明

## Examples

```bash
sudo adduser alice
```

## More options

See `man adduser` or `adduser --help` (if supported) for additional options.
