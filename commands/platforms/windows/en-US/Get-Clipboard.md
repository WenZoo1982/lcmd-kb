## Purpose

Get text or object content from the clipboard.

## Basic syntax

```powershell
Get-Clipboard [OPTIONS]
```

## Common parameters

- `-Format`: Select the clipboard format.
- `-Raw`: Return text as a single string.

## Common examples

```powershell
Get-Clipboard
Get-Clipboard -Raw
```
