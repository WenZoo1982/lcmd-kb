## Purpose

Get the current working location.

## Basic syntax

```powershell
Get-Location [OPTIONS]
```

## Common parameters

- `-PSDrive`: Get the location for a specified drive.
- `-PSProvider`: Filter by provider.

## Common examples

```powershell
Get-Location
Get-Location -PSDrive C
```
