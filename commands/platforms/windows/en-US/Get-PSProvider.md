## Purpose

Get PowerShell providers and their capabilities.

## Basic syntax

```powershell
Get-PSProvider [NAME]
```

## Common parameters

- `-PSProvider`: Filter by provider name.

## Common examples

```powershell
Get-PSProvider
Get-PSProvider FileSystem
```

## More parameters

This page selects practical, frequently used parameters only. Parameters and behavior may vary by PowerShell version, operating system, and module version. Run `Get-Help Get-PSProvider -Full` or consult [Microsoft Learn](https://learn.microsoft.com/powershell/module/microsoft.powershell.core/get-psprovider/) for the complete syntax.
