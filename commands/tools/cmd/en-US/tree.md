## Purpose

Display a directory structure in tree form.

## Syntax

```cmd
tree [path] [/f] [/a]
```

## Common options

/f include files; /a use ASCII characters for the tree.

## Examples

```cmd
tree D:\Project /f /a
```

## Usage notes

Command type: CMD external utility. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `tree /?` to see the full syntax and options available on the current Windows version.
