## Purpose

List files and subdirectories in a directory.

## Syntax

```cmd
dir [drive:][path] [options]
```

## Common options

/a show files with selected attributes; /b bare format; /s recurse; /o sort.

## Examples

```cmd
dir /a /o:n
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `dir /?` to see the full syntax and options available on the current Windows version.
