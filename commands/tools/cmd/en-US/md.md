## Purpose

Create a directory; mkdir is an equivalent command.

## Syntax

```cmd
md [path]
```

## Common options

Can create a path including parent directories that do not yet exist.

## Examples

```cmd
md D:\Work\Reports\2026
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `md /?` to see the full syntax and options available on the current Windows version.
