## Purpose

Display a summary of Windows and computer hardware information.

## Syntax

```cmd
systeminfo [options]
```

## Common options

/fo choose output format; /s query a remote computer (subject to permissions and network configuration).

## Examples

```cmd
systeminfo
```

## Usage notes

Command type: Windows system utility. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `systeminfo /?` to see the full syntax and options available on the current Windows version.
