## Purpose

Display or change the current directory.

## Syntax

```cmd
cd [/d] [path]
```

## Common options

/d changes both drive and directory; .. means the parent directory.

## Examples

```cmd
cd /d D:\Work
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `cd /?` to see the full syntax and options available on the current Windows version.
