## Purpose

Locate executable files and matching paths.

## Syntax

```cmd
where [options] name
```

## Common options

/r search a directory recursively; can locate executables found through PATH.

## Examples

```cmd
where python
```

## Usage notes

Command type: CMD external utility. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `where /?` to see the full syntax and options available on the current Windows version.
