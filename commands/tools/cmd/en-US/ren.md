## Purpose

Rename files or directories without moving them.

## Syntax

```cmd
ren [path] oldname newname
```

## Common options

The new name is normally a name only, not a destination directory path.

## Examples

```cmd
ren draft.txt final.txt
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `ren /?` to see the full syntax and options available on the current Windows version.
