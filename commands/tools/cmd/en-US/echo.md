## Purpose

Display text or control command echoing.

## Syntax

```cmd
echo [text]
```

## Common options

echo text prints text; echo on/off controls command echoing; echo. prints a blank line.

## Examples

```cmd
echo Hello from CMD
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.
