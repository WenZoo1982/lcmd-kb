## Purpose

Shut down, restart, or sign out of a computer.

## Syntax

```cmd
shutdown [options]
```

## Common options

/s shut down; /r restart; /l sign out; /t seconds set a delay; /a abort a pending shutdown.

## Examples

```cmd
shutdown /r /t 60
```

## Usage notes

Command type: Windows system utility. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `shutdown /?` to see the full syntax and options available on the current Windows version.
