## Purpose

Copy one or more files.

## Syntax

```cmd
copy [options] source [destination]
```

## Common options

/y suppress overwrite prompts; /-y prompt before overwrite; /v verify writes.

## Examples

```cmd
copy /y notes.txt D:\Backup\
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `copy /?` to see the full syntax and options available on the current Windows version.
