## Purpose

Move files; can also rename files or directories.

## Syntax

```cmd
move [options] source [destination]
```

## Common options

/y suppress overwrite prompts; /-y prompt before overwrite.

## Examples

```cmd
move report.txt D:\Archive\
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.

## More options

Run `move /?` to see the full syntax and options available on the current Windows version.
