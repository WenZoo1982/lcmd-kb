## Purpose

Display the contents of a text file in the terminal.

## Syntax

```cmd
type file
```

## Common options

Output can be piped to other CMD commands.

## Examples

```cmd
type README.txt
```

## Usage notes

Command type: CMD built-in. Run it in CMD. Some operations require elevation. Verify targets and side effects before deleting, overwriting, or performing system maintenance.
