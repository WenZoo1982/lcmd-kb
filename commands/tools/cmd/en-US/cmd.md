## Purpose

Quickly look up commonly used commands in the Windows Command Prompt (CMD) and batch environment.

## Command categories

- Files and directories: `dir`, `cd`, `copy`, `xcopy`, `robocopy`, `move`, `del`, `ren`, `md`, `rd`, `type`
- Text and file inspection: `find`, `findstr`, `fc`, `attrib`, `tree`, `where`
- System maintenance: `chkdsk`, `sfc`, `shutdown`, `systeminfo`, `schtasks`
- Network diagnostics: `ipconfig`, `ping`, `tracert`, `netstat`
- Process management: `tasklist`, `taskkill`
- Batch basics: `set`, `echo`, `call`

## Usage notes

CMD commands include both CMD built-ins and external Windows utilities. Some commands have different behavior from same-named PowerShell commands or aliases. Confirm which shell is active.

Verify targets before using commands that delete data, repair disks, shut down the computer, or modify scheduled tasks. Elevation may be required.

## More information

This collection focuses on frequently used commands. For full syntax, run `command /?` or consult the official Microsoft Learn documentation.
