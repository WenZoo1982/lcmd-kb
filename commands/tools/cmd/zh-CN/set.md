## 用途

显示、设置或删除当前 CMD 会话的环境变量。

## 基本语法

```cmd
set [变量[=值]]
```

## 常用参数

set 直接显示变量；set NAME=value 设置变量；set NAME= 删除变量。更改通常只对当前 CMD 进程及其子进程有效。

## 常用示例

```cmd
set PATH
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `set /?` 查看当前 Windows 版本提供的完整语法和参数。
