## 用途

显示文本，或控制命令回显。

## 基本语法

```cmd
echo [文本]
```

## 常用参数

echo 文本 输出文本；echo on/off 控制命令回显；echo. 输出空行。

## 常用示例

```cmd
echo Hello from CMD
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。
