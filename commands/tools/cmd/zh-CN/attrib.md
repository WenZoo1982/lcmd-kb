## 用途

查看或修改文件和目录属性。

## 基本语法

```cmd
attrib [+属性|-属性] [路径] [/s] [/d]
```

## 常用参数

R 只读；H 隐藏；S 系统；/s 递归；/d 同时处理目录。

## 常用示例

```cmd
attrib +h private.txt
```

## 使用提示

此命令属于：CMD 外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `attrib /?` 查看当前 Windows 版本提供的完整语法和参数。
