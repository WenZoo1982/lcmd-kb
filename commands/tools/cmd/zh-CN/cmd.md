## 用途

快速查阅 Windows 命令提示符（CMD）及批处理环境中的常用命令。

## 命令分类

- 文件与目录：`dir`、`cd`、`copy`、`xcopy`、`robocopy`、`move`、`del`、`ren`、`md`、`rd`、`type`
- 文本与文件检查：`find`、`findstr`、`fc`、`attrib`、`tree`、`where`
- 系统维护：`chkdsk`、`sfc`、`shutdown`、`systeminfo`、`schtasks`
- 网络诊断：`ipconfig`、`ping`、`tracert`、`netstat`
- 进程管理：`tasklist`、`taskkill`
- 批处理基础：`set`、`echo`、`call`

## 使用提示

CMD 命令分为 CMD 内部命令和 Windows 外部程序。部分命令与 PowerShell 中的同名命令或别名不同，查询时请确认当前终端。

涉及删除、磁盘修复、关机和计划任务的命令，请先确认目标和参数；必要时以管理员身份运行。
