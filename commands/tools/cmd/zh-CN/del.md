## 用途

删除一个或多个文件，不删除目录本身。

## 基本语法

```cmd
del [选项] 文件
```

## 常用参数

/p 每个文件删除前确认；/f 强制删除只读文件；/s 递归；/q 静默模式。

## 常用示例

```cmd
del /p *.tmp
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `del /?` 查看当前 Windows 版本提供的完整语法和参数。
