## 用途

列出目录中的文件和子目录。

## 基本语法

```cmd
dir [驱动器:][路径] [选项]
```

## 常用参数

/a 显示指定属性的文件；/b 仅显示名称；/s 递归列出；/o 排序。

## 常用示例

```cmd
dir /a /o:n
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `dir /?` 查看当前 Windows 版本提供的完整语法和参数。
