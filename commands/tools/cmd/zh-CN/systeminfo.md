## 用途

显示 Windows 和计算机硬件的摘要信息。

## 基本语法

```cmd
systeminfo [选项]
```

## 常用参数

/fo 指定输出格式；/s 查询远程计算机（受权限和网络配置限制）。

## 常用示例

```cmd
systeminfo
```

## 使用提示

此命令属于：Windows 系统工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `systeminfo /?` 查看当前 Windows 版本提供的完整语法和参数。
