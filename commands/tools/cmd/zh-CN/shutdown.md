## 用途

关闭、重启或注销计算机。

## 基本语法

```cmd
shutdown [选项]
```

## 常用参数

/s 关机；/r 重启；/l 注销；/t 秒数 设置延迟；/a 取消待执行的关机。

## 常用示例

```cmd
shutdown /r /t 60
```

## 使用提示

此命令属于：Windows 系统工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `shutdown /?` 查看当前 Windows 版本提供的完整语法和参数。
