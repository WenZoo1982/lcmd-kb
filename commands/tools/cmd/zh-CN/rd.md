## 用途

删除目录；也可使用 rmdir。

## 基本语法

```cmd
rd [/s] [/q] [路径]
```

## 常用参数

/s 删除目录树；/q 静默执行。使用 /s 前确认目标路径，避免误删整个目录树。

## 常用示例

```cmd
rd /s D:\Work\OldBuild
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `rd /?` 查看当前 Windows 版本提供的完整语法和参数。
