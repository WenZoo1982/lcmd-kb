## 用途

显示数据包到目标主机经过的路由路径。

## 基本语法

```cmd
tracert [选项] 目标
```

## 常用参数

/d 不解析路由器名称，通常可加快显示；-h 最大跃点数。

## 常用示例

```cmd
tracert /d example.com
```

## 使用提示

此命令属于：Windows 网络工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `tracert /?` 查看当前 Windows 版本提供的完整语法和参数。
