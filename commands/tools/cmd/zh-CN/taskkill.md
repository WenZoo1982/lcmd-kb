## 用途

结束一个或多个进程。

## 基本语法

```cmd
taskkill [选项]
```

## 常用参数

/pid 指定进程 ID；/im 指定映像名称；/f 强制结束；/t 同时结束子进程。

## 常用示例

```cmd
taskkill /im notepad.exe
```

## 使用提示

此命令属于：Windows 系统工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `taskkill /?` 查看当前 Windows 版本提供的完整语法和参数。
