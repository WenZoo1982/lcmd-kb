## 用途

以树状结构显示目录和子目录。

## 基本语法

```cmd
tree [路径] [/f] [/a]
```

## 常用参数

/f 同时显示文件；/a 使用 ASCII 字符绘制树形结构。

## 常用示例

```cmd
tree D:\Project /f /a
```

## 使用提示

此命令属于：CMD 外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `tree /?` 查看当前 Windows 版本提供的完整语法和参数。
