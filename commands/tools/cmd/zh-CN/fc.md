## 用途

比较两个文件并显示差异。

## 基本语法

```cmd
fc [选项] 文件1 文件2
```

## 常用参数

/b 二进制比较；/n 文本比较时显示行号；/c 忽略大小写。

## 常用示例

```cmd
fc /n old.txt new.txt
```

## 使用提示

此命令属于：CMD 外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `fc /?` 查看当前 Windows 版本提供的完整语法和参数。
