## 用途

在文本中查找指定字符串。

## 基本语法

```cmd
find [选项] "字符串" [文件]
```

## 常用参数

/i 忽略大小写；/n 显示行号；/v 显示不包含字符串的行；/c 仅显示匹配行数。

## 常用示例

```cmd
find /i "error" app.log
```

## 使用提示

此命令属于：CMD 外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `find /?` 查看当前 Windows 版本提供的完整语法和参数。
