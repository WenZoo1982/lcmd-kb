## 用途

显示和管理网络适配器的 IP 配置。

## 基本语法

```cmd
ipconfig [选项]
```

## 常用参数

/all 显示详细配置；/flushdns 清空 DNS 缓存；/release 释放 DHCP 地址；/renew 重新获取地址。

## 常用示例

```cmd
ipconfig /all
```

## 使用提示

此命令属于：Windows 网络工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `ipconfig /?` 查看当前 Windows 版本提供的完整语法和参数。
