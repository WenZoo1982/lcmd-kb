## 用途

复制文件和目录树，支持较多筛选选项。

## 基本语法

```cmd
xcopy 源 [目标] [选项]
```

## 常用参数

/e 复制子目录（包括空目录）；/s 不复制空目录；/i 将目标视为目录；/y 不提示覆盖。

## 常用示例

```cmd
xcopy D:\Project E:\Backup\Project /e /i /y
```

## 使用提示

此命令属于：外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `xcopy /?` 查看当前 Windows 版本提供的完整语法和参数。
