## 用途

检查磁盘文件系统并报告状态；修复选项可能需要管理员权限。

## 基本语法

```cmd
chkdsk [卷:] [选项]
```

## 常用参数

/f 修复错误；/scan 对 NTFS 执行联机扫描；/r 查找坏扇区并尝试恢复可读信息（耗时较长）。

## 常用示例

```cmd
chkdsk C: /scan
```

## 使用提示

此命令属于：Windows 系统工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `chkdsk /?` 查看当前 Windows 版本提供的完整语法和参数。
