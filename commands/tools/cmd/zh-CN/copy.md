## 用途

复制一个或多个文件。

## 基本语法

```cmd
copy [选项] 源 [目标]
```

## 常用参数

/y 覆盖时不提示；/-y 覆盖时提示；/v 验证写入。

## 常用示例

```cmd
copy /y notes.txt D:\Backup\
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `copy /?` 查看当前 Windows 版本提供的完整语法和参数。
