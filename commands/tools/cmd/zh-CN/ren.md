## 用途

重命名文件或目录，不移动其位置。

## 基本语法

```cmd
ren [路径] 原名称 新名称
```

## 常用参数

目标名称通常只写新名称，不指定新的目录路径。

## 常用示例

```cmd
ren draft.txt final.txt
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `ren /?` 查看当前 Windows 版本提供的完整语法和参数。
