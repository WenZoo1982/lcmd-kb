## 用途

测试目标主机的网络连通性和往返时间。

## 基本语法

```cmd
ping [选项] 目标
```

## 常用参数

-n 次数 指定发送次数；-t 持续发送直到停止；-4 或 -6 指定 IP 协议版本。

## 常用示例

```cmd
ping -n 4 example.com
```

## 使用提示

此命令属于：Windows 网络工具。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `ping /?` 查看当前 Windows 版本提供的完整语法和参数。
