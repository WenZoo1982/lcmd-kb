## 用途

按字符串或正则表达式搜索文件内容。

## 基本语法

```cmd
findstr [选项] "模式" [文件...]
```

## 常用参数

/i 忽略大小写；/s 搜索当前目录及子目录；/n 显示行号；/r 使用正则表达式；/c: 将后续内容作为一个搜索字符串。

## 常用示例

```cmd
findstr /s /i /n "failed" *.log
```

## 使用提示

此命令属于：CMD 外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `findstr /?` 查看当前 Windows 版本提供的完整语法和参数。
