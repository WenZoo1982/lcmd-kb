## 用途

移动文件，也可用于重命名文件或目录。

## 基本语法

```cmd
move [选项] 源 [目标]
```

## 常用参数

/y 覆盖时不提示；/-y 覆盖时提示。

## 常用示例

```cmd
move report.txt D:\Archive\
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `move /?` 查看当前 Windows 版本提供的完整语法和参数。
