## 用途

可靠地复制目录树，适合大量文件和备份任务。

## 基本语法

```cmd
robocopy 源目录 目标目录 [文件] [选项]
```

## 常用参数

/e 复制所有子目录（包括空目录）；/z 可重启模式；/mt:n 多线程；/mir 镜像目录（会删除目标端多余文件）。

## 常用示例

```cmd
robocopy D:\Data E:\Backup\Data /e /z /mt:8
```

## 使用提示

此命令属于：外部程序。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `robocopy /?` 查看当前 Windows 版本提供的完整语法和参数。
