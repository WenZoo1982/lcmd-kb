## 用途

从一个批处理脚本调用另一个脚本，并在其结束后继续执行。

## 基本语法

```cmd
call [脚本] [参数]
```

## 常用参数

常用于 .bat/.cmd 脚本之间调用；调用标签可使用 call :label。

## 常用示例

```cmd
call build.cmd
```

## 使用提示

此命令属于：CMD 内部命令。在 CMD 中运行。部分操作需要管理员权限；执行删除、覆盖或系统维护操作前，请确认目标和影响范围。

## 更多参数

运行 `call /?` 查看当前 Windows 版本提供的完整语法和参数。
