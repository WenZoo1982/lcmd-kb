## Purpose

Manage Docker plugins.

## Basic syntax

```bash
docker plugin COMMAND
```

## Common options

- `ls`: List plugins.
- `inspect`: Inspect a plugin.
- `install`: Install a plugin.
- `enable` / `disable`: Enable or disable a plugin.
- `rm`: Remove a plugin.

## Common examples

```bash
docker plugin ls
docker plugin inspect PLUGIN
```

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/plugin/).
