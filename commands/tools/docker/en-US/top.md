## Purpose

Display the running processes of a container.

## Basic syntax

```bash
docker top CONTAINER [ps OPTIONS]
```

## Common options

There are no frequently used options that need separate listing for this command.

## Common examples

```bash
docker top web
docker top web aux
```

## More options

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/top/).
