## Purpose

Log out from a container registry.

## Basic syntax

```bash
docker logout [SERVER]
```

## Common options

There are no frequently used options that need separate listing for this command.

## Common examples

```bash
docker logout
docker logout registry.example.com
```

## More options

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/logout/).
