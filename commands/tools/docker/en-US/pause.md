## Purpose

Pause all processes in one or more containers.

## Basic syntax

```bash
docker pause CONTAINER...
```

## Common options

There are no frequently used options that need separate listing for this command.

## Common examples

```bash
docker pause web
```

## More options

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/pause/).
