## Purpose

Rename an existing container.

## Basic syntax

```bash
docker rename CONTAINER NEW_NAME
```

## Common options

There are no frequently used options that need separate listing for this command.

## Common examples

```bash
docker rename web web-old
```

## More options

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/rename/).
