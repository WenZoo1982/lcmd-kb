## Purpose

Unpause processes in one or more paused containers.

## Basic syntax

```bash
docker unpause CONTAINER...
```

## Common options

There are no frequently used options that need separate listing for this command.

## Common examples

```bash
docker unpause web
```

## More options

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/unpause/).
