## Purpose

Block until one or more containers stop, then print their exit codes.

## Basic syntax

```bash
docker wait CONTAINER...
```

## Common options

There are no frequently used options that need separate listing for this command.

## Common examples

```bash
docker wait job-container
```

## More options

This page covers selected high-frequency, practical options only. For the complete option list and details, see the [official Docker CLI documentation](https://docs.docker.com/reference/cli/docker/wait/).
