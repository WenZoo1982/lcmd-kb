## 用途

Display the running processes of a container.

## 基本语法

```bash
docker top 容器 [ps 选项]
```

## 常用参数

此命令没有需要单独列出的高频参数。

## 常用示例

```bash
docker top web
docker top web aux
```

本文仅收录高频、实用的常见参数。如需了解完整参数及详细说明，请查阅 [Docker CLI 官方文档](https://docs.docker.com/reference/cli/docker/top/)。
