## 用途

Manage Docker plugins.

## 基本语法

```bash
docker plugin 子命令
```

## 常用参数

- `ls`：列出插件。
- `inspect`：查看插件详情。
- `install`：安装插件。
- `enable` / `disable`：启用或禁用插件。
- `rm`：删除插件。

## 常用示例

```bash
docker plugin ls
docker plugin inspect PLUGIN
```
