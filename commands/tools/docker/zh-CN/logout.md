## 用途

Log out from a container registry.

## 基本语法

```bash
docker logout [服务器]
```

## 常用参数

此命令没有需要单独列出的高频参数。

## 常用示例

```bash
docker logout
docker logout registry.example.com
```

## 更多参数

本文仅收录高频、实用的常见参数。如需了解完整参数及详细说明，请查阅 [Docker CLI 官方文档](https://docs.docker.com/reference/cli/docker/logout/)。
