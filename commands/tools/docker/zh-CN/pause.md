## 用途

Pause all processes in one or more containers.

## 基本语法

```bash
docker pause 容器...
```

## 常用参数

此命令没有需要单独列出的高频参数。

## 常用示例

```bash
docker pause web
```

## 更多参数

本文仅收录高频、实用的常见参数。如需了解完整参数及详细说明，请查阅 [Docker CLI 官方文档](https://docs.docker.com/reference/cli/docker/pause/)。
