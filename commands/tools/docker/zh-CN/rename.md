## 用途

Rename an existing container.

## 基本语法

```bash
docker rename 旧名称 新名称
```

## 常用参数

此命令没有需要单独列出的高频参数。

## 常用示例

```bash
docker rename web web-old
```

## 更多参数

本文仅收录高频、实用的常见参数。如需了解完整参数及详细说明，请查阅 [Docker CLI 官方文档](https://docs.docker.com/reference/cli/docker/rename/)。
