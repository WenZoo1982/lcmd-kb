## 用途

在服务器上提供加密远程登录服务；日常启动和重载通常通过系统服务管理器完成。

## 基本语法

```bash
sshd [选项]
```

## 常用参数

- `-t`：检查配置文件和主机密钥，不启动服务。
- `-T`：输出最终生效的配置。
- `-f 文件`：指定配置文件。
- `-p 端口`：指定监听端口。
- `-D`：前台运行。
- `-e`：将日志输出到标准错误。

## 常用示例

```bash
sudo sshd -t
sudo sshd -T
sudo sshd -t -f /etc/ssh/sshd_config
sudo sshd -D -e -p 2222
```

## 使用提示

修改配置后先运行 `sshd -t`，再通过系统服务管理器重载或重启服务；不要在未验证备用登录通道时关闭当前远程会话。
