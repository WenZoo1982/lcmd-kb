## 用途

通过加密的 SSH 连接登录远程主机或执行远程命令。

## 基本语法

```bash
ssh [选项] 用户名@主机
```

## 常用参数

| 想要做什么 | 命令 | 说明 |
|---|---|---|
| 连接远程主机 | `ssh user@example.com` | 使用默认端口 22 |
| 指定端口 | `ssh -p 2222 user@example.com` | 连接指定端口 |
| 指定身份密钥 | `ssh -i ~/.ssh/id_ed25519 user@example.com` | 使用指定私钥认证 |

## 常用示例

```bash
ssh -p 2222 user@192.0.2.10
```

## 必要注意事项

首次连接新主机时，应核对主机密钥指纹，确认连接对象可信。
