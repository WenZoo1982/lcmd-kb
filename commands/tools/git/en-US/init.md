## Purpose

Use this to start tracking a project that is not already a Git repository.

## Basic syntax

```bash
git init
git init <directory>
```

## Common options

- `-b <name>`: Set the initial branch name.
- `--bare`: Create a bare repository, usually for server-side use.

## Common examples

```bash
git init
git init -b main
git init my-project
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-init).
