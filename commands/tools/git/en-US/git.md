# Git command navigation

Git tracks file changes and manages project history. Choose a subcommand based on your task:

| Goal | Query | Description |
|---|---|---|
| Create a local repository | `lcmd git init` | Initialize a repository |
| Inspect repository state | `lcmd git status` | Review changes and staging state |

This is a navigation page. It does not execute Git commands.
