## Purpose

Use this to prepare repository diagnostics for another person. Check the archive before sharing it for sensitive information.

## Basic syntax

```bash
git diagnose
```

## Common options

- `--output-directory=<directory>`: Choose the output directory.
- `--mode=<mode>`: Select the diagnostic data mode.

## Common examples

```bash
git diagnose --output-directory=reports
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-diagnose).
