## Purpose

Use this as a quick entry point when you need a command's usage details.

## Basic syntax

```bash
git help
git help <command>
git <command> -h
```

## Common options

- `-h`: Show concise help for a subcommand.
- `--all`: List available commands and help topics.

## Common examples

```bash
git help
git help rebase
git status -h
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-help).
