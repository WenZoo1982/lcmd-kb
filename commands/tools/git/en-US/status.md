## Purpose

Run this before committing or switching branches to see what has changed.

## Basic syntax

```bash
git status
```

## Common options

- `-s`: Use short output.
- `-b`: Include branch information.
- `--ignored`: Also show ignored files.

## Common examples

```bash
git status
git status -sb
git status --ignored
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-status).
