## Purpose

Use this to inspect how several branches relate to one another.

## Basic syntax

```bash
git show-branch [branches...]
```

## Common options

- `--all`: Include all branches.
- `--current`: Include the current branch.

## Common examples

```bash
git show-branch --all
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-show-branch).
