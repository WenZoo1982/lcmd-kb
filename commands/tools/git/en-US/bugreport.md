## Purpose

Use this when Git itself behaves unexpectedly and you need to provide environment details to maintainers.

## Basic syntax

```bash
git bugreport
```

## Common options

- `-o <directory>`: Choose the output directory.
- `-s <subject>`: Set the report subject.

## Common examples

```bash
git bugreport -o reports
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-bugreport).
