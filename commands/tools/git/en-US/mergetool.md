## Purpose

Use this to open conflicted files in a configured graphical merge tool.

## Basic syntax

```bash
git mergetool
```

## Common options

- `--tool=<tool>`: Select a configured merge tool.
- `--no-prompt`: Do not ask before opening each file.

## Common examples

```bash
git mergetool
```

## More options

This page covers selected commonly used options only. For the complete option list and detailed explanations, see the [official Git documentation](https://git-scm.com/docs/git-mergetool).
