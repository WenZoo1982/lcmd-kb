## Purpose

Git normally maintains repositories automatically. Use this command for manual maintenance or scheduled background maintenance.

## Basic syntax

```bash
git maintenance run
```

## Common options

- `run`: Run maintenance tasks now.
- `start`: Enable scheduled background maintenance.
- `stop`: Stop background maintenance.

## Common examples

```bash
git maintenance run
git maintenance start
```
