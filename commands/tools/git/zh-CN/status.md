## 用途

检查哪些文件已修改、哪些文件已暂存，以及当前分支是否与上游分支同步。

## 基本语法

```bash
git status [选项]
```

## 常用参数

| 想要做什么 | 命令 | 说明 |
|---|---|---|
| 查看完整状态 | `git status` | 显示分支和文件状态 |
| 简洁查看 | `git status --short` | 使用简短状态标记 |

## 常用示例

```bash
git status --short
```

快速检查当前有哪些文件发生变化。

## 必要注意事项

`git status` 只查看状态，不会修改文件或提交更改。
