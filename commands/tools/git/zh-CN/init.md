## 用途

将当前目录初始化为 Git 仓库，之后可以使用 Git 跟踪文件变化。

## 基本语法

```bash
git init [目录]
```

## 常用参数

| 想要做什么 | 命令 | 说明 |
|---|---|---|
| 初始化当前目录 | `git init` | 在当前目录创建仓库 |
| 初始化指定目录 | `git init my-project` | 创建目录并初始化仓库 |

## 常用示例

```bash
cd my-project
git init
```

## 必要注意事项

`git init` 只创建本地仓库，不会自动创建远程仓库，也不会自动提交文件。
