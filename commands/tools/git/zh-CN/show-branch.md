## 用途

在需要快速比较分支历史时查看各分支包含的提交。

## 基本语法

```bash
git show-branch [分支...]
```

## 常用参数

- `--all`：显示所有分支。
- `--current`：包含当前分支。

## 常用示例

```bash
git show-branch --all
```
