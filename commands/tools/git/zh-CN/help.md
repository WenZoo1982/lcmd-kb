## 用途

快速查看 Git 本身或某个子命令的帮助入口。

## 基本语法

```bash
git help
 git help <命令>
git <命令> -h
```

## 常用参数

- `-h`：显示子命令简要帮助。
- `--all`：列出可用命令和帮助主题。

## 常用示例

```bash
git help
git help rebase
git status -h
```

本文仅收录常用参数。如需了解完整参数及详细说明，请查阅 [Git 官方文档](https://git-scm.com/docs/git-help)。
