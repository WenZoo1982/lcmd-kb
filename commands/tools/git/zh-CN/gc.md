## 用途

手动触发仓库清理和压缩；通常由 Git 自动维护，不建议频繁手动执行。

## 基本语法

```bash
git gc
```

## 常用参数

- `--prune=<时间>`：清理早于指定时间的不可达对象。
- `--aggressive`：更彻底但更耗时的优化，不建议日常使用。

## 常用示例

```bash
git gc
git gc --prune=now
```
