## 用途

撤销暂存、回退提交，或让当前分支回到某个历史位置。`--hard` 会直接丢弃工作区改动，使用前务必确认。

## 基本语法

```bash
git reset [--soft | --mixed | --hard] <目标版本>
git reset <文件>
```

## 常用参数

- `--soft`：只移动分支指针，改动保留在暂存区。
- `--mixed`：移动分支指针并取消暂存，默认模式。
- `--hard`：移动分支指针，并用目标版本覆盖暂存区和工作区，未保存的改动可能丢失。
- `--`：分隔选项与文件路径。

## 常用示例

```bash
# 取消某个文件的暂存，保留文件修改
git reset README.md

# 撤销最近一次提交，但保留改动在暂存区
git reset --soft HEAD~1

# 撤销最近一次提交，保留改动但取消暂存
git reset HEAD~1

# 强制回到上一个提交（会丢弃未保存的改动）
git reset --hard HEAD~1
```
